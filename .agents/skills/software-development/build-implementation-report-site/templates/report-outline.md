# 実装レポートSite構成

## 冒頭

- 対象PRまたは変更
- 一文で示す変更目的
- 変更前と変更後の短い対比
- 主要な結果。単位、分母、計測条件を併記する

## 変更の全体像

- システム全体のどこが変わったか
- ロジック本体、検証ハーネス、回帰テストの役割
- 対象外とした範囲

## 処理フロー

- 入力と初期判定
- 通常経路
- 分岐条件と各分岐の処理
- ループ条件と戻り先
- 早期終了と安全上限
- 計算のみの処理と外部I/Oを伴う処理の凡例

各段階には次を短く書く。

- 対象
- 実行する処理
- 外部I/Oの有無
- 次へ進む条件

## 実装対応

- 変更前の責務または処理
- 変更後の責務または処理
- 主要な関数とフロー上の位置
- 採用しなかった案と理由

## 検証

- base SHAと変更後SHA
- 共通の入力、renderer、設定、ハーネス
- 実行コマンド
- ケース別の結果
- 解消前、base後、変更後の画像
- 性能指標と品質指標
- 計測対象外と既知の制約

## レビュー観点

- 処理順と分岐条件
- 推定と実測の境界
- 悪化防止と安全上限
- 出力品質
- テストで固定した不変条件
