# 実験契約

結果を見る前に比較の意味を固定するため、実験ごとに次を記録する。

## 問いと判定

- **問い**：実験で一つだけ判断する内容。
- **仮説**：どの変数がどの指標へ影響すると予想するか。
- **採用基準**：採用に必要な閾値。品質と計算量を分ける。
- **棄却条件**：平均が改善しても棄却する悪化、未解決、安全上限超過。

結果を見てから閾値を変えた場合は、事後分析として明示する。

## 比較対象

各variantに不変のIDを付け、表示名と分ける。

- source revisionまたはartifact digest
- dirtyな作業ツリーを含むか
- 設定一式
- モデル、renderer、deploymentなど外部依存の版
- 実行成果物の保存先

「main」「旧版」「新版」「現在」は時間とともに指す内容が変わるため、表示名としてだけ使う。

## 条件とケース

- **固定条件**：入力、fixture、seed、フォント、画像、renderer、hardware、cacheなど。
- **操作する変数**：比較対象間で意図的に変える値。
- **ケース集合**：選定理由、件数、除外条件。
- **反復**：非決定性や計測誤差がある場合の回数。

固定条件を変えた再実験は新しいrun IDを持たせる。旧runを上書きしない。

## 指標

各指標には次を定義する。

- 名前と計算式
- 単位と小数の丸め方
- 大きいほどよいか、小さいほどよいか
- 分母と対象ケース
- 集計方法。合計、平均、中央値、パーセンタイル、最大値など
- 計測開始と終了
- 欠損、timeout、未解決の扱い

時間は、純粋な計算時間、外部I/Oを含む処理時間、end-to-endのwall-clockを分ける。短い処理はwarm-up後に反復し、代表値とばらつきを示す。

## ケース別resultの最低項目

- run ID、variant ID、case ID
- 入力と出力artifactへの参照
- statusと終了理由
- 解決または終了した段階。実装が出力した値を使い、画像から推測しない
- 初期値と最終値
- 品質指標
- 試行回数、render回数、外部I/O回数
- 計測時間とそのscope
- error、timeout、欠損理由

集計値はこのresult集合から再生成できるようにする。
