# 実験レポートSiteのレビューチェックリスト

## 実験契約

- 問いが一つの判断に絞られているか。
- 仮説、採用基準、棄却条件が結果と分けて書かれているか。
- 操作する変数と固定条件を区別したか。
- fixtureなどの条件変更を別runとして扱ったか。

## 比較対象と再現性

- variant ID、commit SHA、作業ツリー状態、設定を記録したか。
- renderer、モデル、deploymentなど外部依存を特定したか。
- 入力、コマンド、result、画像、ログを追跡できるか。
- 相対名だけで比較対象を特定していないか。

## 指標と計測

- 各指標に単位、分母、計算式、集計方法があるか。
- 未解決、timeout、欠損の扱いを決めたか。
- 計算時間、外部I/O、wall-clockを区別したか。
- 初回処理と追加処理を区別したか。
- warm-up、反復回数、ばらつきを必要に応じて示したか。

## 結果

- 集計値を機械可読なケース別resultから再生成できるか。
- 平均だけでなく、分布、最悪値、未解決、悪化を示したか。
- 全ケースで入力、基準、候補を同じ条件で比較できるか。
- 終了段階を実装の出力から取得したか。
- 移動量、縮小量、残差など、解消率以外の品質も確認したか。
- 採用基準に反する結果を省いていないか。

## 解釈

- 観測事実と、その理由についての推論を分けたか。
- 交絡要因と実環境との差を記録したか。
- ケース集合から一般化できない範囲を明示したか。
- 採用、保留、棄却の判断を採用基準へ対応づけたか。

## 表示と成果物

- 表、集計、画像説明が同じresultを参照しているか。
- run ID、variant ID、case IDで画像と数値を対応づけたか。
- デスクトップとモバイルで比較順が保たれるか。
- リンク切れ、画像欠損、重複ケースがないか。
- Siteの版と成果物の版が一致しているか。
