# 実験レポートSite構成

## 冒頭

- 実験の問い
- 比較対象と主要な違い
- 採用基準に照らした結論
- 主要な改善と悪化。単位、分母、計測範囲を併記する

## 実験契約

- 仮説
- 採用基準と棄却条件
- 比較対象の不変ID、source revision、設定
- 固定条件
- 操作する変数と探索範囲
- 評価ケースと反復回数
- 指標の定義
- 実験対象外

## 実行環境と再現手順

- 実行日時と環境
- commit SHAと作業ツリー状態
- renderer、モデル、外部サービスの版またはdeployment
- 実行コマンド
- 入力、設定、生データ、画像、ログの保存先
- 非決定性、warm-up、cacheの扱い

## 全体結果

- 採用基準ごとの判定
- ケース数と成功、未解決、悪化の内訳
- 主要指標の分布と最悪値
- 実行回数と計測時間
- 結論を変えうる例外

## パラメータ探索

- 候補値と選定理由
- 候補ごとの品質指標とコスト
- 境界値の挙動
- 採用値より大きい値または小さい値を棄却した理由

探索を実施していない場合、この節は置かない。

## ケース比較

全ケースについて、同じ順序と縮尺で次を示す。

- resolverや変換を適用する前の入力
- 基準実装または基準設定の結果
- 候補実装または候補設定の結果
- 解決または終了した段階
- 初期値、最終値、下限や上限
- 移動量、縮小量、残差などの品質指標
- render回数、試行回数、計測時間
- 基準との差と、そのケースから分かること

## 結果の解釈

- 仮説を支持または棄却する根拠
- 改善した経路と悪化した経路
- 品質と計算量の両立関係
- 観測結果からは保証できないこと

## 制約と次の判断

- ケース集合の偏り
- 計測誤差と非決定性
- 実環境との差
- 追加実験が必要な条件
- 採用、保留、棄却の判断
