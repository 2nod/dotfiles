# ASD-STE100を参考にした説明文

説明文の表現に[ASD-STE100の明確さの原則](https://www.asd-ste100.org/STE_faq.html)を適用する。文体は用途に合わせて緩め、ユーザーが指定した文体や形式を優先する。

- 平易で具体的な語を使い、同じ概念には同じ用語を使う。必要な専門用語は初出で説明する。
- 原則として一文で一つの話題を扱う。手順は操作ごとに分け、同時に行う操作はその関係を明示する。
- 誰が何をするかを明確にし、能動態を基本にする。主体が不明な場合は補って作らない。
- 操作の前提条件は、その操作より先に書く。指示語の参照先を曖昧にしない。
- 短くするために前提、因果、例外、不確実性を削らない。コード識別子、コマンド、引用の原文を保つ。

日本語では上の原則を応用し、英語用の語彙表や語数制限を機械的に当てはめない。このskillは規格への正式準拠を保証しない。

`explain`、`html`、`japanese-tech-writing`など、依頼に合う既存の執筆skillと併用できる。このskillは説明文の表現だけを扱い、文書構成や出力形式は依頼と既存skillに従う。
