# タスク一覧の更新

未完了タスクの正本は、ユーザーが指定したタスク管理ディレクトリの Markdown 一覧とする。
タスク作成と一覧更新を別々に完了させない。

## 新規タスク

1. タスクの目的、最初の一手、完了条件を確認する。
2. Codexタスクを作成する。
3. 直後に未完了一覧へ登録する。

登録する項目は、タスク名、状態、次の一手、関連タスクスレッド名である。
開始前は原則として状態を「次の一手あり」にする。
外部の返答やユーザーの決定が必要なときだけ、それぞれ「外部待ち」「判断待ち」にする。

## 更新と完了

ユーザーが優先順位、次の一手、保留理由を決めたら一覧を更新する。
実行状態が `idle` であることを完了の根拠にしない。
ユーザーまたは関連タスクスレッドで完了を確認できた場合だけ、未完了一覧から外して日次ログへ移す。

## 手動作成されたタスク

CodexのUIから直接作られたタスクは、自動では検出できない。
ユーザーが「未完了一覧を同期して」と言ったときに、既存タスクを確認して一覧へ取り込む。
